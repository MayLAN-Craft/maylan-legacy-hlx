# 🚀 MaylanHLX (Half-Life X Plugin)

**MaylanHLX** — это простой, но стильный плагин для Minecraft Paper/Spigot, который автоматически анонсирует подтверждение "Half-Life" при обнаружении заданного паттерна в чате. Идеально подходит для добавления атмосферы игры Half-Life 3 на ваш сервер!

## ✨ Функционал

* **Автоматический триггер:** Плагин постоянно отслеживает все сообщения в чате (асинхронно).
* **Настраиваемый паттерн:** Определяет, какое слово или символ должно присутствовать в сообщении игрока для активации.
* **Стилизованное сообщение:** Отправляет красивое, заметное сообщение в стиле Half-Life (λ), оформленное золотым цветом и жирным шрифтом.
* **Режимы анонса:** Позволяет выбирать:
    * 🟢 **Бродкаст (Broadcast):** Сообщение видно всем онлайн игрокам.
    * 🔵 **Только автор (Player Only):** Сообщение видно только тому, кто его отправил.

## ⚙️ Как это работает?

1. Игрок пишет в чат сообщение, например: `Я подтверждаю 3!`
2. HLXPlugin проверяет, содержит ли сообщение заданный паттерн (`pattern`).
3. Если совпадение найдено, плагин активирует соответствующий режим анонса (Бродкаст или Только автор).

## 🛠️ Настройка (Config)

Настроить поведение плагина очень просто через файл `config.yml`.

### `config.yml`

```yaml
# Что ищем в сообщении (по умолчанию — символ '3')
pattern: "3"

# Сообщение в стиле Half-Life (λ — греческая лямбда)
message: "λ Half-Life 3 confirmed!"

# true — показать всем, false — только автору
broadcast: true
```

| Параметр | Тип данных | Описание | Примеры |
| :--- | :--- | :--- | :--- |
| `pattern` | String | Строка, которую плагин будет искать в чате. | `"3"`, `"HLX"`, `"lambda"` |
| `message` | String | Текст сообщения, которое будет отправлено игрокам. | `"λ Half-Life 3 confirmed!"` |
| `broadcast` | Boolean | Если `true`, сообщение видно всем; если `false`, только автору. | `true` (по умолчанию) / `false` |

### Пример использования:

Если вы установили:
```yaml
pattern: "HLX"
message: "Мы подтверждаем HLX на сервере!"
broadcast: false
```
И игрок пишет: `"Это мое сообщение о HLX"` — то увидит это только сам игрок.

## 📥 Установка (Installation)

1. **Компиляция:** Соберите проект с помощью Maven или Gradle.
2. **Получение файла:** Найдите сгенерированный файл `.jar` (обычно `MaylanHLX-1.0.0.jar`).
3. **Размещение:** Поместите этот JAR-файл в папку `plugins/` вашего сервера Minecraft.
4. **Запуск:** Перезапустите или загрузите сервер, и плагин HLXPlugin автоматически активируется!
